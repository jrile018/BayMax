# BayMax Evidence Lab

A recorded evidence workbench for humanitarian classification, multilingual retrieval and audio transcription. All three new benchmark components are pending until measured and independently reviewed. This Static Space has no server-side inference, private Bucket mount or credentials.

HUMSET provides real historical humanitarian excerpts and taxonomy references. We retain authored adversarial controls because HUMSET is not gold for quantities, access, location spans or report reconstruction. Upstream sources remain canonical. Examples here are explicitly synthetic replays; no raw third-party reports or private media are packaged.

E5 adds a useful source-search role; Whisper adds a permitted-audio transcription role. Their usefulness and quality must be measured before adoption. Their outputs remain unconfirmed proposals, with source attribution and human review before accepted operational state.

A proposed private Bucket is for compact finalized typed numeric simulation packs: reproducible configuration, seed, snapshots, numeric aggregates and integrity manifests. It excludes raw reports, audio/transcripts, names, sensitive locations, full datasets and model weights. Live transfer is pending a native canary plus fresh-process roundtrip through the actual adapter. The current adapter cannot store arbitrary F1/WER; reviewed benchmark results belong in this versioned package.

See results.json for pinned sources, component status and methodology. MIT applies to this package code and authored synthetic examples; linked datasets and models retain their own terms.
