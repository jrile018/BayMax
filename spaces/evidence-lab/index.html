Why these Hugging Face features?

Dataset

HUMSET gives us real, historical humanitarian excerpts with category labels in English, Spanish and French. It tests classification. The authored controls still test quantities, negation and unsupported claims.

Read the HUMSET card

Space

A free Static Space makes methods, source links, failures and reviewed comparisons easy to inspect. Processing happens separately. The demo stays usable without downloading a model.

Private storage

Store finalized numeric run packs so a run's configuration, seed and snapshots can be retrieved and checked across machines. No raw reports, audio, personal information or model weights belong there.

Useful model roles

Qwen predicts report categories. E5 ranks passages relevant to a query. Whisper turns permitted audio into timestamped text. New pilots are pending; planned models are not measured results.

What a result needs before it appears here

Independent review, pinned sources, actual sample counts, metric denominators and a receipt matching every published value. Missing or failed runs never appear as perfect scores. Audio needs permitted clips and independent reference transcripts. Retrieval needs independent query-to-passage judgments and hard negatives.
