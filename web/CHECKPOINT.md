# Web checkpoint

Knight26 Response Lab is a map-first, read-only training replay. The full-window dark shell frames a local 2D OpenStreetMap vector map, collapsible layer/contact and inspector panels, and a bottom replay dock. The map uses 444 real OSM roads, 199 buildings, and 40 landuse features from the supplied area. Routes, fire overlays, vehicle movement, needs, stocks, and outcomes are explicitly constructed mock replay records. Frames and positions come only from `GET /api/frame?index=N`; the browser does not interpolate or solve routes.

Assets load in this order: `style.css`, `upstream-panel-rail.js`, `app.js`. The first script is a classic-script adaptation of the pure `resolveHudRailLayout` helper from God's Eye View `src/ui/panelRailGeometry.js`, pinned at `591f299d11f38a612629a274463196d57ae3862e`. It places the desktop map toolbar in a measured obstacle-safe corridor. Its full MIT copyright, permission and warranty text remains in the JavaScript header for saved inline previews. `UPSTREAM_LICENSE.txt` and `REFERENCES.md` record the source and changes. No upstream map service, data feed, model, imagery, or asset is bundled.

The client supports layer toggles; selecting, focusing, and following recorded units; local search; road/fire/closure inspection; replay speed, stepping, scrubbing, event jumps, and shortcuts; pointer-centered zoom, SVG-accurate pan, keyboard pan/zoom; straight-line measure; local annotation pins; coverage checks; fullscreen; source provenance; and responsive mobile drawers. The Data inspector shows acquisition versus full-way context bounds, OSM edit-date range, retrieval time, and snapshot hash. Source labels and attribution stay visible. Unknown ETA and distance remain unknown.
